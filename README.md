# 游乐设施日常检验与缺陷闭环平台

基于Vue3、Naive UI、Pinia、Vue Router、TanStack Query、Axios、WebSocket和Vite的独立前端工程。数据默认保存在localStorage，无需后端即可演示。

## 功能

- 检验任务列表、关键词和状态/区域筛选、统计概览。
- 新建检验任务，逐项录入磨损、异响、制动、锁止和安全装置结果。
- 缺陷处置泳道、风险排序、责任人调整和资源冲突提示。
- 状态流转校验、停用隔离、复测与闭环审计。
- 换件链管理：设备、检验任务、部件履历、缺陷处置和放行记录串成一条链。
  - 换件登记以现场盖章时刻为准，同一部件同一时段只服务一台设备，后到记录待核且不覆盖先到结果。
  - 部件履历更新后，未放行的检验和复验结论失效，需按新部件重新确认；已开放班次保留原依据并追加复核。
  - 保存失败自动从最后一笔完整换件链恢复；凭幂等键判重，重复提交不新增履历。
  - 旧检验数据升级时按设备补录部件序列号，补不全的标待核不参与放行；总览、看板和审计展示同一有效链条。
- JSON记录导出、版本号和完整操作时间线。

## 启动

```bash
npm install
npm run dev
```

访问`http://localhost:18463`。

## 构建

```bash
npm run build
```

## 换件链规则验证

```bash
npm test
```

在Node中运行真实store的行为测试，覆盖盖章冲突裁决、结论失效与重新确认、放行复核、失败恢复、幂等判重和旧数据升级。
