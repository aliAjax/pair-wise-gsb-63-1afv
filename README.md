# 游乐设施日常检验与缺陷闭环平台

基于Vue3、Naive UI、Pinia、Vue Router、TanStack Query、Axios、WebSocket和Vite的独立前端工程。数据默认保存在localStorage，无需后端即可演示。

## 功能

- 检验任务列表、关键词和状态/区域筛选、统计概览。
- 新建检验任务，逐项录入磨损、异响、制动、锁止和安全装置结果。
- 缺陷处置泳道、风险排序、责任人调整和资源冲突提示。
- 状态流转校验、停用隔离、复测与闭环审计。
- 换件链：设备、检验任务、部件履历、缺陷处置与放行记录串联；换件登记以现场盖章时刻为准，同一部件同一时段只服务一台设备，后到记录待核不覆盖先到结果，重复提交不新增履历。
- 部件履历更新后，未放行的检验/复验结论自动失效并按新部件重新确认；已开放班次保留原依据并追加复核。
- 保存失败从最后一笔完整换件链恢复；旧检验数据升级按设备补部件序列号，补不全标待核不参与放行；总览、看板、审计展示同一有效链条。
- JSON记录导出、版本号和完整操作时间线。

## 启动

```bash

npm run dev
```
